# Streets of Prague

- The game's camera is strictly top-down. Judge visual changes by what shows from above:
  outlines, colour, texture and shadows (height only comes through in shadow length),
  never by how something would look from street level.
- `README.md` is the public front page: what the game is, how to run it, credits. Keep it
  short. How the game works, the URL options, the pipeline and deploying go in
  `docs/handbook.md` (formerly the README); credits stay in the README.
- `docs/evidence/` and `screenshots/` are local working records and aren't committed.
